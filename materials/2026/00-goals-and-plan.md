# KCL Hack 2026 フロントエンド初回講座 設計メモ

## 目的

KCL Hack 2026 の初回フロントエンド講座では、初心者が「Webアプリは小さな部品とデータの組み合わせで作れる」と理解し、ハッカソン中に自分で画面を足せる状態を目指します。

今年版は、去年の TypeScript 講座と Next.js 講座を別々に扱うのではなく、`KCL Shop` という1つのフロントエンド完結アプリを作りながら統合して学ぶ構成にします。

## 対象者

- プログラミング初心者、または C / Python などは少し触ったことがある人
- HTML / CSS / JavaScript の経験が浅い人
- ハッカソンで最初の画面、一覧、フォーム、検索を作りたい人
- 余裕があれば React / Next.js の設計をもう少し深く触りたい中級者

## 到達目標

講座後に参加者ができること:

- TypeScript の `type` で商品データの形を定義できる
- 配列、オブジェクト、`map` / `filter` を画面表示に使える
- React コンポーネントを props で再利用できる
- `useState` で検索欄や選択状態を管理できる
- `useEffect` の役割を、検索結果更新や `localStorage` 保存で説明できる
- Next.js App Router の `app/`, `page.tsx`, `layout.tsx`, `[id]` の意味がわかる
- `Link` を使って一覧、詳細、フォームのページをつなげられる
- バックエンドなしでもハッカソン用のプロトタイプを作り始められる

## 作るもの

完成物は `Lecture0-NextJs/web` の `KCL Shop` です。

- 商品一覧
- 商品詳細
- 検索
- カテゴリ絞り込み
- お気に入り
- カート風UI
- 注文フォーム風ページ
- JSON と XML の簡単な比較

実際の決済、ログイン、DB、API、Supabase、Prisma は扱いません。初回講座ではフロントエンドの部品、状態、ページ遷移に集中します。

90分版:

| 時間 | 内容 | ゴール |

| 0:00-0:10 | 何を作るか、ディレクトリ構造 | 全体像をつかむ |

120分版では、`useEffect`、`localStorage`、注文フォームまで講義内で扱います。90分版では `useEffect` 以降を発展課題または講師デモに回します。

## 教材方針

- 初心者には「なぜ必要か」を先に伝え、コードの細部は後から見る
- 中級者には「状態を直接書き換えない」「コンポーネント境界」「型の役割」を明確にする
- バックエンドを持ち込まず、ブラウザだけで動く範囲に限定する
- 完成アプリを丸写しするのではなく、各段階で画面が変わるチェックポイントを置く
- 参加者がハッカソンで再利用できる言葉にする: 一覧、カード、詳細、フォーム、フィルター

## 追加ツールについて

現時点では、追加のMCPや外部サービス設定は不要です。資料作成、HTMLスライド、Next.js アプリの検証はローカル環境だけで完結します。
